## Contextual historical sources

The following sources support only the later-adoption context in the catalogue
record. They are distinct from the primary grant and do not supply claim text,
dimensions, performance values, or model inputs.

- EPFL, “Reymond Clavel receives Joseph F. Engelberger Robotics Award,”
  https://actu.epfl.ch/news/reymond-clavel-receives-joseph-f-engelberger-robot/:
  Clavel’s team invented the parallel Delta robot in 1985 and licensed it to
  Demaurex for packaging-industry production in 1987.
- International Federation of Robotics, “Robot History,”
  https://ifr.org/robot-history: Demaurex’s 1992 installation for Roland used
  six Delta robots to load pretzels into blister trays.
